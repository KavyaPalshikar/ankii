ANKIII ❤ Hosting Guide

Upload only these website files/folders:

- `index.html`
- `apology.html`
- `understand.html`
- `moments.html`
- `finale.html`
- `from-mota.html`
- `styles.css`
- `script.js`
- `assets/`
- `.nojekyll`

Fastest option: Netlify

1. Open `https://app.netlify.com/drop`
2. Upload the prepared folder: `deploy-ankii-site`
3. Netlify will give you a live link instantly
4. Send that link on WhatsApp

GitHub Pages option

1. Create a new GitHub repo
2. Upload the contents of `deploy-ankii-site`
3. Enable GitHub Pages from the main branch
4. Share the generated link

Important

- Do not upload the full `New project` folder, because it contains unrelated app files.
- Upload only the clean deploy folder or the exact files listed above.
- Keep the `assets` folder next to the HTML files, otherwise photos will break.
